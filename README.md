🔐 PHP CORS Handling – Training Project
This project was created as part of backend training to understand how CORS, HTTP methods, and request filtering work in PHP.
The script demonstrates how to control allowed origins, block specific domains, handle preflight requests, and return JSON responses.

📌 Features
Allowing and blocking specific origins

Handling GET, POST, and OPTIONS requests

Returning proper HTTP status codes

Managing CORS headers

Processing JSON POST data

Basic protection against unauthorized cross‑origin requests

Practical demonstration of server‑side request validation

🧰 Technologies Used
PHP (XAMPP environment)

HTTP Headers

JSON responses

Fetch API (from the HTML page)

🚀 How to Run the Project
Place the PHP file inside your local server (Laragon / XAMPP / WAMP).

Start the server.

Open the HTML page that sends requests to this PHP backend.

Test GET, POST, and OPTIONS requests.

Check the browser console and network tab for CORS behavior.
